FastAPI Asynchronous Architecture

FastAPI is a modern web framework built on top of Starlette and Pydantic that achieves performance on par with NodeJS and Go.

Path Operation Functions: async def vs def

FastAPI handles endpoints declared with async def differently from standard def endpoints:

  • async def: Executed directly on the main event loop thread. If an async endpoint executes blocking I/O (e.g. time.sleep or synchronous database calls), it blocks the entire event loop for all requests.
  • def: Automatically dispatched by FastAPI to an external thread pool (anyio worker threads). This allows blocking synchronous code to run without halting the event loop.

Dependency Injection (Depends)

FastAPI features a hierarchical Dependency Injection system. Dependencies can declare sub-dependencies, yield resources (enabling cleanup via context managers), and be shared across routers.
