Preventing Hallucinations in RAG Pipelines

The primary vulnerability of RAG architectures is ungrounded generation: the model fabricates facts when retrieved chunks are insufficient or irrelevant.

The Two-Stage Guardrail

  1. Similarity Score Thresholding (No-Context Branch): If the top retrieved chunk has a cosine similarity score below a tuned threshold (e.g. 0.35), the pipeline must bypass the LLM generator entirely. It returns a deterministic refusal message ("I do not have enough relevant context in the provided documents to answer this question."). This eliminates 100% of hallucinations on out-of-domain queries and saves generation latency and API cost.
  2. Strict Citation Enforcement: The generator system prompt instructs the model to cite chunk markers [Chunk X] for every fact asserted. Claims lacking citations are penalized during automated evaluation.
